# vineethkalluru.com

My personal site and blog. Built with [Astro](https://astro.build), deployed to GitHub Pages.

- **New post:** add a Markdown file to `src/pages/blog/` (copy the frontmatter from an existing post). `draft: true` hides it.
- **Name, bio, links, projects:** `src/site.ts`
- **Local preview:** `npm install && npm run dev`

Pushing to `main` deploys.
